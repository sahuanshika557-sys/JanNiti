# JanNiti AI (जननीति एआई) — Phase 2
### *"Turning Citizen Voices into Smarter Public Infrastructure Decision Intelligence"*

**JanNiti AI** is an AI-powered **Digital Public Good (DPG)** and decision-support infrastructure platform for India that bridges grassroots citizen demands and national infrastructure capital planning. Rather than serving as another isolated complaint ticketing system, JanNiti AI converts high-volume citizen grievances into **evidence-based public infrastructure decision intelligence**.

```
CITIZEN VOICE (Voice / Text / Multimodal Photos in 10+ Languages)
        ↓
CANONICAL NORMALIZATION & MULTIMODAL GEMINI UNDERSTANDING
        ↓
SEMANTIC DUPLICATE & ISSUE CLUSTER DETECTION (e.g. CL-1042)
        ↓
MULTI-SOURCE EVIDENCE FUSION (Citizen Demand, Infra Gap, Demographics, Trends)
        ↓
INFRASTRUCTURE GAP ENGINE (10 Vital Categories: 0–100 Score)
        ↓
PREDICTIVE DEMAND FORECASTING & SEASONAL INTELLIGENCE (+34% Monsoon Surge)
        ↓
EQUITY & SILENT AREA DETECTION (Digital Participation Index / Under-reporting)
        ↓
WHAT-IF POLICY SIMULATOR (Compare Option A vs B vs C)
        ↓
CAPITAL BUDGET PORTFOLIO OPTIMIZER (₹X Cr Knapsack Utility Allocation)
        ↓
AI POLICY BRIEF GENERATOR (WHAT, WHY, EVIDENCE, RISKS, TRADE-OFFS)
        ↓
HUMAN-IN-THE-LOOP GOVERNANCE CONSOLE (Approve / Modify / Reject / Audit Log)
        ↓
CLOSED-LOOP IMPACT VERIFICATION (Before-vs-After Metrics & Citizen Feedback)
```

## 🌟 Flagship Decision Intelligence Capabilities

### 1. Public Infrastructure Intelligence Engine (Issue Clustering)
- **Semantic Clustering**: Aggregates hundreds of isolated citizen complaints into unified high-impact **Issue Clusters** (e.g., `CL-1042` with 127 related citizen reports).
- **Cluster Confidence Rating**: Real-time statistical confidence (e.g., 94% confidence) indicating geographic and semantic cohesion.
- **Root-Cause Inference vs. Observed Evidence**: Clearly distinguishes observed citizen symptom signals from AI causal hypotheses (e.g. *Inadequate drainage eroding road subgrade*).

### 2. Multi-Source Evidence Fusion (10 Dimensions)
- Combines 10 empirical layers into an auditable **Evidence Panel**:
  - Citizen Demand Intensity (92%)
  - Infrastructure Deficit Index (88%)
  - Demographic Population Reach (81%)
  - Demand Growth Velocity (89%)
  - Socio-Economic Vulnerability Multiplier (73%)
- Computes both **Priority Score (0–100)** and **Confidence Tier** (`HIGH CONFIDENCE`, `MEDIUM CONFIDENCE`, `LOW CONFIDENCE`).

### 3. 10-Sector Infrastructure Gap Engine
- Canonical 0–100 gap diagnostic scoring across 10 vital public infrastructure domains:
  1. *Roads & Bridges*
  2. *Water Supply & Jal Jeevan*
  3. *Sanitation & Solid Waste*
  4. *Healthcare & Primary Health Centres*
  5. *School & Education Infrastructure*
  6. *Electricity & Power Distribution*
  7. *Public Transport & Mobility*
  8. *Stormwater Drainage & Flood Control*
  9. *Public Safety & Street Lighting*
  10. *Digital Connectivity & Telecom*
- Evaluates demand against MoHUA / CPHEEO benchmark standards.

### 4. 30-Day Demand Velocity & Seasonal Intelligence
- **Explainable Time-Series Forecasting**: Computes 30-day projected grievance volumes with Mean Absolute Error (MAE) validation.
- **Seasonal Risk Telemetry**: Pre-monsoon stormwater overflow warnings (+34% expected spike) and summer groundwater deficit alerts.

### 5. Equity Multiplier & "Silent Areas" Detection
- **Digital Participation Index (DPI)**: Measures reporting density per lakh population to identify digital exclusion.
- **Under-Reporting Risk Classifier**: Flags high-population rural wards with severe infrastructure deficits as *Potential Under-Reported Regions* and applies a 1.2x – 1.45x equity boost.

### 6. What-If Policy Intervention Simulator
- Simulates and contrasts interventions for any issue cluster:
  - **Option A**: Localized emergency patch repair
  - **Option B**: Sector-specific standard overhaul
  - **Option C (Recommended)**: Integrated multi-agency public infrastructure modernization
- Real-time estimates for demand reduction %, gap reduction %, population benefited, and implementation feasibility.

### 7. Capital Budget Portfolio Optimizer
- Enter available budget in ₹ Crores (e.g. ₹10 Cr, ₹25 Cr, ₹50 Cr).
- Adjust strategic weights (Population, Urgency, Equity, Gap, Cost Efficiency) to compute the mathematical optimal portfolio maximizing public impact per rupee.

### 8. Human-in-the-Loop Governance & Immutable Audit Log
- **Constitutional Human Primacy**: AI advises; authorized officers approve, modify, or reject recommendations.
- **Human Overrides**: Preserves AI baseline and stores human-adjusted priority separately with mandatory justification.
- **Tamper-Evident Audit Log**: Timestamped, searchable audit trail of every government action.

### 9. Closed-Loop Impact Verification & Citizen Feedback
- **Before-vs-After KPIs**: Direct empirical tracking (e.g. 820 → 410 monthly grievances, Gap Score 86 → 51, 52% net improvement).
- **Visual Photographic Proof**: Before and after photographic comparison.
- **Citizen Feedback Loop**: Interactive community voting (*Improved / Partially / Not Improved*) recalculating satisfaction ratings in real-time.

### 10. AI Model Transparency & Fairness
- Transparent Model Cards for Gemini Multimodal, Priority Engine, Clustering, and Forecasting.
- Data Quality Scorecard (88/100) evaluating completeness, freshness, coverage, and source reliability.

## 🚀 5–7 Minute Judge Demo Flow (Step-by-Step)

1. **Citizen Voice Submission**:
   - Open Citizen Portal, select **Hindi** (हिन्दी).
   - Tap microphone and speak or click visual sample: *"हमारे इलाके में बारिश के समय सड़क पर बहुत पानी भर जाता है और सड़क खराब हो जाती है।"*
   - Real-time Gemini analysis extracts *Road & Drainage*, *Critical Urgency*, and *AI Visual Assessment*.
2. **Issue Clustering**:
   - The system aggregates this with 120+ geocoded reports into **Issue Cluster `CL-1042`** with **94% Cluster Confidence**.
3. **Intelligence Center ("What Needs Attention Now?")**:
   - View prioritized active issue clusters, root-cause inferences vs observed evidence, and time-series anomaly alerts.
4. **Area Intelligence & "Why This Area?" Explainer**:
   - Open Area Intelligence for **Lucknow** vs **Kanpur Nagar**.
   - Inspect the 5-bar Evidence Fusion breakdown and 10-sector Gap Matrix.
5. **Policy Simulator & Budget Allocator**:
   - Compare Option A (surface repair) vs Option C (integrated road + drainage).
   - Enter ₹10 Crore budget and adjust sliders to see AI-optimized project selection.
6. **One-Click AI Policy Brief**:
   - Click *Generate Policy Brief* to view the structured, grounded decision brief and print PDF.
7. **Human-in-the-Loop Governance**:
   - Open Governance console, approve the project or apply a Human Override with official notes.
   - Verify the entry is recorded in the Immutable Audit Log.
8. **Impact Verification**:
   - Open Impact Verification to review before-and-after metrics (820 → 410 grievances) and cast a citizen satisfaction rating.

## 📦 Running Locally

### 1. Prerequisites
- Node.js 18+ and npm installed

### 2. Installation
```bash
# Clone repository
git clone https://github.com/your-username/janniti-ai.git
cd janniti-ai

# Install dependencies for both server & client
npm install
cd server && npm install
cd ../client && npm install
cd ..
```

### 3. Environment Setup
```bash
# In server/.env
PORT=5000
GEMINI_API_KEY=your_gemini_api_key_here
```
*(Note: If no Gemini API key is provided, the platform automatically runs on high-fidelity deterministic DPI fallback models with zero crashes).*

### 4. Start Development Servers
```bash
# From workspace root
npm run dev
```
- **Client**: `http://localhost:5173`
- **Server API**: `http://localhost:5000`
